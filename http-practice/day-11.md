# Day 11: HTTP Fundamentals



## 1. Request Information



- Request URL: https://glyphutrung.top/index.php

- Request Method: GET

- Status Code: 200 OK



## 2. Request Header



- Accept: Includes text/html and other accepted media types.

- Meaning: Describes the content types the client can accept or prefer.



## 3. Response Header



- Content-Type: text/html; charset=UTF-8

- Meaning: The response declares its content as HTML using UTF-8 character encoding.



## 4. Response Body



- Observed content: HTML document.

- It is not a JSON response.



## 5. QA Reflection



A 200 OK status does not prove that the entire website

or its business functions work correctly.



A tester must inspect the response content and compare

the actual behavior with the expected result.
